# AXIOM v0.3.0-beta.1

> **Status:** beta release preparation. This document is not evidence that packages have been published.

## Direction

Beta.1 focuses on expanding the current AXIOM engineering workflow without replacing the existing Control Center design.

## Existing capabilities retained

- Agent/model optimization and quantization planning surfaces.
- Local daemon health and workspace API foundations.
- Model and dataset inventory foundations.
- Hardware-aware training-plan generation.
- Administrator setup, login, inactivity timeout, and password-change flow.
- Security hardening for filesystem handling and HTTP response construction.

## Planned or incomplete work

The following are not represented as complete until their backend implementation and tests land:

- Visual training workflow builder with graph validation.
- MCP agent profiles and server-enforced tool permissions.
- Rich model compatibility scoring.
- Dataset profiling and privacy reports.
- Persistent experiment tracking and evaluation regression gates.
- A real local inference/API playground.
- Historical CPU/RAM/GPU telemetry.
- Comprehensive configuration/security audit reporting.

Estimated quantization sizes must not be labelled as measured performance. Runtime benchmarks require a real supported backend and reproducible test conditions.

## Distribution

GitHub Releases and PyPI remain the primary distribution targets. npm, APT, Homebrew, Scoop/WinGet, AUR, and OCI images require validated packaging and configured publishing credentials before they can be advertised as available.
