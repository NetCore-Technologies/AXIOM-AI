# AXIOM v0.3.0-beta.1 — preparation notes

<!-- AXIOM-RELEASE-BETA1-UPDATE:START -->
## Feature update

This beta includes the bounded JSONL dataset profiling foundation, structural
field summaries, privacy-review warnings, workspace API foundations and
existing model, optimisation, quantization and GUI components.

Further work is planned for visual training workflows, agent-tool permissions,
model compatibility, richer quantization comparisons, persistent experiments,
repeatable evaluation, local API exploration, resource history and security
diagnostics. These roadmap items should not be read as a claim that all of
those end-to-end capabilities shipped in this release.

See [ROADMAP.md](../../ROADMAP.md) and
[Feature-Implementation-Plan.md](../Feature-Implementation-Plan.md).
<!-- AXIOM-RELEASE-BETA1-UPDATE:END -->

- Adds bounded JSONL profiling: row validity, duplicates, field types, null rates and likely-sensitive field-name warnings.
- Adds `axiom dataset profile PATH` and a `data/`-scoped API for the existing Dataset page.
- Preserves the existing Control Center theme.
- Other feature areas remain roadmap items until backend implementation and tests are complete.
- This is preparation documentation, not proof of publication.
