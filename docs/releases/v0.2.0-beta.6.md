# AXIOM v0.2.0-beta.6

Release focus: efficient Linux distribution.

## Linux assets

- The recommended `linux-x64.tar.gz` bundle keeps the PyInstaller runtime
  unpacked between launches.
- The shell installer downloads and verifies `SHA256SUMS` before activation.
- The DEB and AppImage use the same onedir runtime layout.
- The one-file ELF remains available for a single-download portable path.
- CI smoke-tests the version command, loopback daemon health endpoint, tarball
  contents, DEB metadata, and installer syntax on an Ubuntu runner.

## Website

- The hero sentence now reads naturally: “Know what your machine can run
  before you start.”
- The top-left logo and favicon use the same current Saturn-ring SVG asset.

## Beta status

AXIOM remains a terminal-first local CLI and loopback daemon. Release assets
are built on native Linux runners and checksums are published with every
release.
