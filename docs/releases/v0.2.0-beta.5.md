# AXIOM v0.2.0-beta.5

## Highlights

- Agent/model optimizer with workload profiles and hardware-aware planning.
- Quantization lab with measured-performance reporting.
- Dataset quality inspection in the optimization workflow.
- Trusted model/output filesystem boundaries.
- Secure administrator verifier storage without persistent clear-text browser credentials.
- Improved end-to-end authentication validation and production build checks.

## Security

Beta.5 addresses the reported model-path injection findings and the administrator clear-text browser-storage issue. Model paths are resolved and constrained to trusted AXIOM roots before filesystem operations. Administrator verifier material is not persisted as clear-text `localStorage` data.

## Verification

Ruff, pytest, ESLint, TypeScript/Vite build, Python compilation, Playwright E2E, and `git diff --check` must all pass before the release tag is created. The release gate also requires the new `main` CodeQL analysis to report zero open code-scanning alerts.
