# AXIOM v0.2.0-beta.5

Release date: 2026-10-08

## Highlights

- Agent and model optimization planning.
- Quantization recommendations based on detected hardware.
- AXIOM Control Center optimizer UI.
- Secure administrator verifier storage.
- Trusted filesystem boundaries for model and optimizer paths.
- Hardened Playwright CI/E2E validation.

## Security

Beta.5 addresses path-injection findings in the model optimization and policy-audit filesystem flows. User-controlled paths are canonicalized with  and accepted only when  proves they remain inside AXIOM-owned roots.

Administrator authentication no longer persists the administrator verifier in clear-text browser storage.
