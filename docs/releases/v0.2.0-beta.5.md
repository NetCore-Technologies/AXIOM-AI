# AXIOM v0.2.0-beta.5

**Release:** 2026-10-08

Beta.5 delivers the optimizer/quantization control-center work together with filesystem-boundary hardening and administrator credential-storage hardening.

## Highlights

- Agent/model optimization workflow with hardware inspection and quantization recommendations.
- Quantization Lab and Beta.5 optimizer Control Center UI.
- Trusted model/output filesystem boundaries for optimizer and policy-audit operations.
- Administrator verifier material moved away from clear-text browser storage.
- Playwright E2E login coverage and Linux browser dependency setup for CI.
- CodeQL quality/security hardening and release validation.
