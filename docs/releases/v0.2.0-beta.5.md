# AXIOM v0.2.0-beta.5

**Build AI. Own AI.**

Beta.5 delivers the AXIOM optimizer and quantization workflow together with security hardening for administrator storage and model filesystem boundaries.

## Highlights

- Agent/model optimization planning with hardware-aware recommendations.
- Quantization planning and runtime-focused optimization workflow.
- Real-benchmark language that distinguishes estimates from measured throughput.
- Hardened model filesystem boundaries against path traversal/path injection.
- Administrator verifier storage moved away from clear-text persistent browser storage.
- Improved Playwright CI execution with installed browser dependencies.
- Frontend lint, TypeScript/Vite production build, Python tests and compile checks passing at release time.
