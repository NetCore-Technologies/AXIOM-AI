# AXIOM v0.2.0-beta.5

## 🤖 Agent Model Optimizer

Beta.5 introduces a questionnaire-driven optimization workflow.

### Eight agent profiles

1. Coding Agent
2. Reasoning Agent
3. Research Agent
4. General Assistant
5. Automation Agent
6. Math Agent
7. Writing Agent
8. Multilingual Agent

### Optimization pipeline

The workflow can:

- select an agent profile
- use a Hugging Face or local model
- inspect CPU/RAM/GPU/VRAM
- estimate model memory requirements
- select a quantization target
- create a runtime-focused bundle
- retain inference-critical files
- omit non-runtime repository artifacts
- target 10 tok/s by default
- benchmark supported GGUF runtimes when available

10 tok/s remains a target until measured on the actual device.
