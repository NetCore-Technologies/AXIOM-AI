## Security

Beta.5 addresses path-injection findings in the model optimization and
policy-audit filesystem flows. User-controlled paths are canonicalized with
`Path.resolve()` and accepted only when `Path.is_relative_to()` proves they
remain inside AXIOM-owned roots.

Administrator authentication no longer persists the administrator verifier in clear-text browser storage.
