# AXIOM v0.2.0-beta.5 — historical optimizer and security notes

> This is a historical beta.5 record. For the current product boundary and
> supported packages, use [the release-build guide](../releases.md).

**Date prepared:** 2026-10-09
**Status:** Beta prerelease notes; macOS DMG assets are attached by the macOS release workflow after publication.

## Highlights

- AXIOM optimizer and quantization planning UI.
- Hardware-aware model recommendations and agent profiles.
- Dataset inspection and model-runtime planning improvements.
- Administrator storage and filesystem path hardening.
- Expanded Python, frontend and Playwright validation.

Each DMG includes the native-architecture AXIOM CLI executable and the static

attached beside each DMG.

**macOS security note:** these DMGs are currently unsigned and not notarized.
They are distribution bundles, not signed native installers. Any API-backed
frontend behavior described by that historical workflow required a separately
configured backend.
