# AXIOM AI v0.2.0-beta.5

> **Status: UNVERIFIED BETA**

Beta.5 introduces the interactive Agent Optimizer workflow.

## Interactive optimizer

AXIOM asks the user:

1. Coding
2. Cybersecurity
3. General Assistant
4. Reasoning
5. Research
6. Tool / Agentic AI
7. Creative / Writing
8. Custom

It then asks for:

- speed vs quality preference
- target tokens/sec
- context length
- model ID/path

## Hardware-aware optimization

AXIOM detects available CPU, RAM, GPU backend and VRAM where supported, then creates a hardware-aware optimization profile.

## Quantization

Beta.5 recommends an appropriate precision/quantization profile based on the detected hardware and selected goal. Actual throughput is not considered achieved until benchmarked on the target device.

## Hugging Face / local models

The optimizer accepts a Hugging Face model ID or local model path as its model input.

## Safety

AXIOM does not remove or bypass model safety controls. The optimizer focuses on model efficiency, hardware compatibility and configurable deployment profiles.

## Verification

Beta.5 remains an **unverified beta release** until the supported model formats, quantization backends and target hardware combinations have been validated.
