# AXIOM v0.2.0-beta.7 — preparation notes

**Status:** unreleased target. The GitHub release, workflow runs, and uploaded
assets must be checked before describing beta.7 as published.

## Product focus

Beta.7 keeps AXIOM small and terminal-first. The user-facing path is:

1. start with `axiom` or read `axiom guide`;
2. inspect a model and validate a JSONL dataset;
3. read the local hardware and generate a conservative plan;
4. use `axiom daemon` only when a local script needs JSON over HTTP.

The daemon binds to loopback and asks the operating system for a free port when
the port is `0`. A non-loopback bind requires an explicit network opt-in. The
daemon is not a hosted service or an inference server.

## Packaging target

- Linux x86_64: reusable tarball, DEB, AppImage, one-file ELF, installer, and
  checksums when the Linux workflow completes successfully.
- Windows x64: executable and installer assets when the Windows workflow
  completes successfully.
- macOS arm64 and x64: CLI DMG/tarball bundles when the macOS workflow
  completes successfully.
- macOS and non-x86 Linux fallback: isolated Python installation from the
  repository's `main` branch, requiring Python 3.11+.

The [release-build guide](../releases.md) explains the intended assets. The
GitHub [Actions runs](https://github.com/NetCore-Technologies/AXIOM-AI/actions)
and [Releases page](https://github.com/NetCore-Technologies/AXIOM-AI/releases)
remain authoritative for what actually built and uploaded.
