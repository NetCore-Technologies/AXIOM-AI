# AXIOM v0.2.0-beta.7

**Prepared:** 2026-10-09
**Channel:** Beta / prerelease
**Platform packages:** Windows, Linux, macOS Apple Silicon (arm64), macOS Intel (x64), subject to successful platform workflows.

## Highlights

- AXIOM optimizer and quantization Control Center improvements.
- Agent/model optimization planning with recommendations separated from measured benchmark results.
- Added macOS CLI packaging workflow for Apple Silicon and Intel Macs, producing a DMG, tarball, and checksums.
- Improved Playwright CI setup and login-flow coverage.
- Updated release documentation and project roadmap.

## Verification

The release preparation runs Ruff, pytest, ESLint, TypeScript/Vite production build, Python compileall, Playwright E2E, and `git diff --check`. Platform artifacts are attached only by successful workflow jobs.

## Security status

Open CodeQL path-injection findings are not claimed fixed by this release. Current count observed at preparation time: **0** open alerts (the live GitHub security dashboard is authoritative). Do not treat this beta as a certification that those findings are resolved. A security advisory will remain a draft until affected versions and a validated patched version are confirmed.

## macOS installation

Download the matching `macos-arm64` or `macos-x64` DMG, or the matching tarball. Verify the published SHA-256 checksum before running. Packages are not Apple Developer ID signed or notarized.
