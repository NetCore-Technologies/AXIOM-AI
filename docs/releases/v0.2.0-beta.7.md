## Validation

This release script requires Ruff, pytest, ESLint, the TypeScript/Vite production build, Python compilation, Playwright E2E, and git diff --check to pass before tagging.

## Security status

This is a beta pre-release. The current GitHub CodeQL dashboard still reports open Python py/path-injection alerts. This release does **not** claim those alerts have been remediated or dismissed. Do not treat beta.7 as a security-certified production release. Follow-up security fixes must validate user-controlled model paths against trusted roots and then be confirmed by a fresh CodeQL scan.
