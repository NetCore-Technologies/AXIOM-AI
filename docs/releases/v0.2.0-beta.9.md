# AXIOM v0.2.0-beta.9 — daemon workspace API and bundled web UI

## Highlights

- Read-only daemon routes for models, datasets, training plans, agent model
  plans, and Headroom status.
- The daemon serves the bundled web UI at `/ui/`.
- Every release package and the PyPI wheel include the web UI.
- Tag pushes publish the Python package to PyPI after a version check.

## Security

- Paths must stay inside the daemon's working directory.
- Non-loopback `Host` headers are refused unless `--allow-network` is set.

## Verification boundary

Plans and hardware fit values are estimates, not benchmark results.

## Web UI

- Optimizer, Quantization Lab and Beta.5 panels share the app theme tokens.
- Quantization Lab shows an FP16, INT8 and INT4 size comparison (rough estimate).
