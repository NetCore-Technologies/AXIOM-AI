# AXIOM v0.2.0-beta.8 — terminal-first CLI and local workflow

**Status:** release preparation. The GitHub release, workflow result, assets,
and checksums are the source of truth after publication.

## Highlights

- Bare `axiom` prints the command map and starts the local daemon on an
  operating-system-selected loopback port.
- `axiom daemon --json` emits stable ready/stopped records for local scripts.
- `axiom headroom` discovers the optional external Headroom CLI and exposes
  explicit doctor, proxy, and dashboard passthroughs without installing,
  starting, or measuring Headroom during discovery.
- The landing page explains the command path, shows the local health endpoint,
  and offers platform-specific installer commands.
- Linux installation supports pinned releases, user-scoped paths, checksums,
  archive-layout validation, and a reusable onedir bundle.

## Verification boundary

Plans, hardware fit estimates, tool presence, and third-party optimization
effects are not benchmark results. Verify the exact beta.8 workflow run and
published checksums before treating an asset as a release artifact.
