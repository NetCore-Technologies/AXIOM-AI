# AXIOM AI Engineering Platform — v0.3.0-b.4

**Build AI. Own AI.**

## Overview

This release advances AXIOM toward a more complete local-first AI engineering platform, bringing together the Control Center, CLI, API, diagnostics, workflow tooling, and cross-platform packaging.

## Highlights

### Control Center and GUI
- Expanded the Control Center with discoverable platform modules and navigation.
- Added the Module Explorer for discovering GUI pages, CLI command families, and API capabilities.
- Improved the API Playground with predefined, read-only GET endpoints and bounded requests.
- Continued work on administrator sign-in, remembered sessions, first-boot onboarding, and consistent AXIOM branding.
- Improved workflow discovery, saved designs, templates, and revision history.

### Diagnostics and support
- Added diagnostics capabilities across the core, API, CLI, and GUI.
- Added `axiom doctor --json` for machine-readable diagnostic output.
- Added `axiom support-bundle` for generating privacy-minimized support archives.
- Added roadmap auditing through `axiom roadmap audit --json`.
- Documented diagnostics and support-bundle behaviour.

### API and platform tooling
- Expanded API request handling and consistent error reporting.
- Improved API Playground endpoint restrictions and frontend-to-client integration.
- Added or expanded roadmap, diagnostics, and workspace tests.
- Continued integration of agent profiles, dataset inspection, and workflow management.

### Roadmap and documentation
- Improved access to the 120-item roadmap from the Control Center.
- Added or updated documentation for platform capabilities, diagnostics, and support.
- Continued aligning documented feature status with actual implementation.

### Build and release engineering
- Prepare synchronized application and package versions for this release.
- Validate the release through automated tests, linting, production builds, and end-to-end checks.
- Build platform-specific distributions and installer artifacts where supported by the release workflow.
- Include checksums and standardized release notes with published artifacts.
- Update Docker image metadata and publish the versioned image when the registry workflow and credentials are configured.

## Security and privacy
- The API Playground is intended for predefined, read-only GET requests rather than arbitrary URLs or mutating methods.
- Support bundles are designed to exclude credentials, environment variables, model weights, datasets, and other sensitive local information.
- AXIOM remains focused on local-first operation without requiring a cloud account for local administrator


## Beta Status

AXIOM is actively under development.

Some Control Center sections represent platform capabilities that are still being implemented. Full training execution, evaluation execution and production runtime serving remain under development.

This beta establishes the unified AXIOM architecture, Control Center and release pipeline.
