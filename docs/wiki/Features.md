# Features

## Dataset profiling

The beta includes bounded JSONL profiling, row statistics, duplicate and
invalid-row detection, field type/null summaries and potential sensitive
field-name warnings.

## Model engineering and workspace

The repository contains model inspection, registry and optimisation
foundations, quantization components and workspace APIs for datasets,
runtime information and training plans.

## GUI

The application includes Dashboard, Models, Datasets, Training, Evaluation,
Runtime, MCP, Diagnostics and Logs sections.

## Planned enhancements

The roadmap covers visual workflows, agent permissions, compatibility
analysis, quantization comparison, experiment history, repeatable evaluation,
local API exploration, telemetry and security diagnostics.

Not every planned feature is a completed end-to-end capability.
