# Getting Started

## Requirements

- >=3.11
- Node.js 20 or newer for the npm launcher
- Python available on PATH

## Install

    python -m pip install axiom-all
    axiom --help

## Create a project

    axiom init my-first-ai
    cd my-first-ai

## npm launcher

    npm install --global @netcore-technologies/axiom-cli@beta

The npm package launches the installed Python CLI; it does not replace it.

See the [repository README](https://github.com/NetCore-Technologies/AXIOM-AI#readme) for current information.
