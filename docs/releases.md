# AXIOM Release Builds

GitHub releases publish Windows x64 EXE/portable ZIP and Linux x64 AppImage/DEB packages.

Release assets are generated by GitHub Actions on native runners.

## Control Center and API status

The current beta includes a routed React/Vite Control Center and a local FastAPI backend. The GUI is connected to health, hardware, optimizer profile/plan, model optimization, and read-only policy-audit endpoints. Model inventory, datasets, training execution, evaluation execution, runtime serving, MCP inspection, and event logs remain roadmap work until their API contracts are available.
