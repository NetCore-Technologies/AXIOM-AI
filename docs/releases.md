# AXIOM Release Builds

GitHub releases publish Windows x64 packages and Linux x64 AppImage, DEB,
portable tarball, and one-file executable assets.

Release assets are generated by GitHub Actions on native runners.

For Linux, the tarball is the recommended download for repeated terminal use:
it keeps the PyInstaller runtime unpacked so `axiom` and the local daemon do
not extract the full application into a temporary directory on every launch.
The shell installer verifies `SHA256SUMS` before activating that bundle.

## Current product boundary

The supported product surface is the static landing page, the terminal-first
Python CLI, and the dependency-free loopback daemon. Internal API modules are
used by selected CLI workflows; AXIOM does not ship a hosted web workspace.
