# AXIOM Release Builds

GitHub releases publish Windows x64 EXE/portable ZIP and Linux x64 AppImage/DEB packages.

Release assets are generated by GitHub Actions on native runners.

## Current product boundary

The supported product surface is the static landing page, the terminal-first
Python CLI, and the dependency-free loopback daemon. Internal API modules are
used by selected CLI workflows; AXIOM does not ship a hosted web workspace.
