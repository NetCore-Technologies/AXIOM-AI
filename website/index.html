Know what your machine can run. Before you start.

AXIOM is a local CLI and daemon for AI projects. It inspects model files, checks datasets, reads your hardware, and turns the result into a next command you can act on.

Install the CLI ↓ Read the source ↗
$axiom

Shows the useful commands, then opens the local daemon on a free port.

Inspect the work. Check the machine. Choose the next move.

AXIOM keeps the decisions around an AI run in the terminal: what the files contain, whether the data is usable, what the hardware can support, and which local step makes sense next.

Read the implementation ↗
  1. 01

    Inspect a model

    axiom model inspect ./models/my-model

    See the model format, configuration, size, and capabilities before choosing a runtime.

  2. 02

    Validate the data

    axiom dataset validate ./data/train.jsonl

    Catch malformed records and duplicate data while the fix is still cheap.

  3. 03

    Read the machine

    axiom system info

    Check the operating system, CPU, memory, GPU, VRAM, and CUDA availability locally.

  4. 04

    Plan the run

    axiom train plan 7 --method qlora

    Get a hardware-aware starting plan. AXIOM estimates; it does not claim to have run your training.

Start with axiom.

Install the CLI, run the bare command, and AXIOM will print the available commands before starting its loopback daemon on an available port.

Stop the daemon with Ctrl-C. It stays on your machine unless you explicitly allow network access.
